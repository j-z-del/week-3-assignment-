
# Week 3 Assignment on Conditions and Loops

## Assignment: Grade Reporter & Bug Hunt

### Files

- `grade_reporter.py`: Uses loops and conditions to calculate grades, count passes and failures, and calculate the average score.
- `bug_hunt.py`: Fixes three bugs in a while loop program that adds the numbers from 1 to 5.

### Bug Hunt Reflection

The hardest bug to find was the incorrect while loop condition because it did not produce an error message. The program ran but stopped at 4 instead of including 5. I knew something was wrong because the answer was 10 instead of the expected 15.
